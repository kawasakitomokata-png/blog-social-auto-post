# TourBox × YMM4（ゆっくりMovieMaker4）ショートカット割り当て案

TourBox には YMM4 用の公式プリセットが無いため、TourBox Console（設定アプリ）で
「キーボードショートカットの送信」を各操作子に割り当てることで、擬似的にYMM4のショートカットを再現します。

参照元のショートカット一覧: https://note.com/wagawaga_wagasi/n/nfcf68288cedb

## 前提

- 対象は TourBox NEO / Elite 系の共通操作子（Elite Plus など追加ボタンがある機種は空きボタンにさらに割り当て可能）
- 使用する操作子: `Tall`（大ボタン）, `Short`（小ボタン）, `Top`, `Side`, `C1`, `C2`,
  `Knob`（回転+押し込み）, `Dial`（回転+押し込み）, `Scroll`（回転+押し込み）, `D-Pad`（上下左右）
- 1つの物理ボタンに **シングルクリック / ダブルクリック / 長押し** を割り当てて複数機能を収納
- `Side` を押しながら別の操作子を動かす「組み合わせ（コンビネーション）」機能で上級者向け操作を収納
- TourBox Console のバージョン/機種によりダブルクリックや組み合わせが使えない操作子がある場合は、
  適宜別の空きボタンに読み替えてください

| YMM4機能 | ショートカットキー | TourBox割り当て |
|---|---|---|
| 切り取り | Ctrl+X | C1（シングル） |
| コピー | Ctrl+C | C2（シングル） |
| 貼り付け | Ctrl+V | Knob 押し込み |
| 削除 | DELETE | Short |
| 元に戻す | Ctrl+Z | Dial 左回転 |
| やり直し | Ctrl+Y / Ctrl+Shift+Z | Dial 右回転 |
| プロジェクトを保存 | Ctrl+S | Top（シングル） |
| プロジェクトを別名で保存 | Ctrl+Shift+S | Tall 長押し（無ければ C2 ダブルクリック） |
| 再生/一時停止 | SPACE | Tall（シングル） |

## TourBox Console での設定手順（概要）

1. TourBox Console を起動し、対象アプリとして YMM4（`YMM4.exe`）を追加する
   （個別アプリ設定が無ければ「デフォルト」プロファイルに設定してもよい）
2. 上表の各操作子を選択し、「キーボードショートカットの送信（Keyboard Shortcut）」を選んで
   対応するキー入力（例: `Ctrl+X`）を登録する
3. ダブルクリック／長押しが必要な項目は、操作子設定画面内のタブ（Single/Double/Long Press）を
   切り替えてそれぞれ登録する
4. `Side` を押しながらの組み合わせ操作は、「コンビネーションキー」機能から `Side` を修飾ボタンとして
   選択し、対応する操作（Knob回転やD-Pad方向）にキーを割り当てる
5. 設定後、YMM4を実際に操作しながら誤動作がないか確認し、必要に応じて頻度の高い機能を
   押しやすいボタン（Tall/Top/Side）へ入れ替える

## 補足

- お使いの機種（NEO / Elite / Elite Plus）やお好みの手（左右）によって最適な配置は変わります。
  上記は一案なので、実際の使用感に合わせて調整してください。
- ダブルクリック/長押しの反応時間はTourBox Console側で調整可能です。誤爆する場合は
  しきい値を伸ばすか、頻度の高い機能はシングルクリックに寄せてください。
- ボタンによっては「長押し」タブ自体が無い場合があります（例: `Top`）。その際は
  空いている別のボタンのダブルクリック/長押しに読み替えてください。
